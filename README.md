# Eva Dental & Aesthetics | مركز إيڤا لطب وجراحة الأسنان والتجميل

منصة وواجهة رقمية متكاملة لعيادات **مركز إيڤا** (Eva Dental & Aesthetics) لطب وجراحة الأسنان وجراحة التجميل والجلدية والليزر في مصر (أركان بلازا - الشيخ زايد / التسعين الشمالي - التجمع الخامس).

الموقع مبني بنظام **Next.js 15 (App Router)**، مع دعم كامل للاتجاه من اليمين لليسار (**RTL**)، وتصميم Minimalist Editorial هادئ ومريح للمستخدم وبأعلى معايير الـ UX السريري.

---

## 🌟 أبرز المميزات (Features)

- **هوية بصرية طبية فاخرة (Editorial Luxury UI):** لوحة ألوان دافئة ومريحة للمريض (Warm Alabaster & Forest Green) بدون أي بهرجة أو عناصر مشتتة.
- **تصفح تخصصات تفاعلي (Interactive Services Directory):** استعراض لأهم الخدمات (فينيرز، زراعة ألمانية فورية، تقويم شفاف، تبييض زووم، ليزر كانديلا، علاج جذور ميكروسكوبي).
- **نافذة تفاصيل الإجراء السريري (Clinical Detail Modal):** نافذة منبثقة تفاعلية عند الضغط على أي كارد لعرض بروتوكول العلاج خطوة بخطوة، معايير الراحة، الضمان، والتكلفة وخيارات التقسيط عبر ValU.
- **مقارنة تفاعلية قبل وبعد (Interactive Before / After Slider):** سلايدر سريري مرن بمقارنة بصرية دقيقة لحالات تجميل الأسنان وعلاج البشرة مع إمكانية التبديل بين العرض المدمج أو جنباً إلى جنب.
- **الفريق الطبي (Consultants):** بروفايلات واقعية ومميزة لنخبة من كبار الاستشاريين المصريين.
- **حجز فوري وذكي (Instant Appointment Booking):** محاكاة لنظام حجز إلكتروني يصدر كود تأكيد طبي فوري، مع إمكانية التمرير التلقائي وحجز خدمة محددة مباشرة من بطاقتها.
- **تواصل مرن (Direct WhatsApp & Hotline):** زر عائم تفاعلي لواتساب والخط الساخن الموحد 19842.
- **متجاوب 100% (Fully Responsive):** تجربة سلسة على جميع الهواتف الذكية، الأجهزة اللوحية، والشاشات المكتبية.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Framework:** [Next.js 15](https://nextjs.org/) (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Typography:** IBM Plex Sans Arabic (Google Fonts)

## 🚀 كيفية التشغيل محلياً (Getting Started)

1. **استنساخ المشروع (Clone the repository):**
   ```bash
   git clone https://github.com/ziadmohamedmarz0uk/eva-dental-aesthetics.git
   cd eva-dental-aesthetics
   ```

2. **تثبيت الحزم (Install dependencies):**
   ```bash
   npm install
   ```

3. **تشغيل بيئة التطوير (Run development server):**
   ```bash
   npm run dev
   ```

4. افتح المتصفح على: `http://localhost:3000`
